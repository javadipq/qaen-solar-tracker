# Qaen Dual-Axis Solar Tracker (ردیاب خورشیدی دو محوره قاین)

سیستم ردیاب خودکار خورشیدی دو محوره بر اساس الگوریتم دقیق نجومی NOAA و ماژول ساعت سخت‌افزاری DS3231 برای شهر **قاین** (خراسان جنوبی).

## مشخصات جغرافیایی قاین
* **عرض جغرافیایی (Latitude):** `33.7275° N`
* **طول جغرافیایی (Longitude):** `59.1844° E`
* **منطقه زمانی (Timezone):** `UTC + 3.5` (ایران)

---

## ویژگی‌ها
* **عملکرد کاملاً آفلاین:** بدون نیاز به اینترنت یا Wi-Fi (استفاده از RTC با باتری پشتیبان).
* **دقت زاویه‌ای بالا:** محاسبه بلادرنگ زوایای سمْت (Azimuth) و ارتفاع (Elevation) با تقریب کمتر از ۰.۰۱ درجه.
* **حالت پارک شبانه (Night Parking):** بازگشت خودکار به جهت مشرق پس از غروب آفتاب.
* **محافظت مکانیکی:** دارای محدوده مرده (Deadband) نیم درجه برای کاهش استهلاک و مصرف انرژی استپر موتورها.

---

## شماتیک اتصالات

| قطعه | پایه ماژول | پایه میکروکنترلر |
| :--- | :--- | :--- |
| **DS3231 RTC** | SDA | پین SDA (پیش‌فرض I2C) |
| **DS3231 RTC** | SCL | پین SCL (پیش‌فرض I2C) |
| **درایور محور سمْت (Azimuth)** | STEP | پین D4 |
| **درایور محور سمْت (Azimuth)** | DIR | پین D5 |
| **درایور محور ارتفاع (Elevation)** | STEP | پین D6 |
| **درایور محور ارتفاع (Elevation)** | DIR | پین D7 |

---

## نحوه استفاده
1. فایل `qaen_solar_tracker.ino` را در Arduino IDE باز کنید.
2. کتابخانه `RTClib` اثر Adafruit را از Library Manager نصب کنید.
3. کد را روی برد خود (Arduino Uno/Mega/Nano یا ESP32) آپلود کنید.
